> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the backend foundation for M7.6 Agent Studio — schema for paused/terminated lifecycle, 8 new IPC endpoints (pause/resume/terminate/setMode/setAlwaysOn/setSkills/wake-up/reset-session/hire-from-ui), repository methods with activity dual-write, router pause check, full TDD.

**Architecture:** New columns `paused_at`/`terminated_at`/`pause_reason` extend the existing `agents` table (migration 0010). The `AgentStatus` union gains `"paused"` and `"terminated"` discriminants. Two new `ActivityAction`s (`agent.mode_changed`, `agent.always_on_changed`) round out the M7.7 vocabulary. Repository methods follow the established M7-C pattern: capture previous row → UPDATE → `recordActivity`. IPC handlers reuse `restartIfRunning` for spawn-affecting mutations (mode, skills) and skip restart for metadata-only (alwaysOn). Router gains a pause guard before `writeStdin`. PR-B (UI) plugs in on top.

**Tech Stack:** better-sqlite3 (prepared statements, transactions), Zod (IPC payload validation), Electron IPC, vitest. No new deps.

**Baseline:** 411 tests passing on master (`ea05e2a`) — 383 main + 28 renderer + 33 shared. Branch: `feat/m7.6-pr-a`.

**Spec reference:** [`docs/superpowers/specs/2026-05-11-paperclip-gaps-ux-governance-design.md §1`](../specs/2026-05-11-paperclip-gaps-ux-governance-design.md). The §1 design is locked. PR-B (UI) gets its own plan after PR-A merges.

## Decisions locked in before plan

1. **Migration number is 0010**, not the spec's stale `0008`. Existing migrations end at `0009_activity_events.sql`.
2. **`AgentStatus` union extends with `"paused"` and `"terminated"`** — both are valid runtime states. UI hides `terminated` from default lists (PR-B concern). Router uses the union value directly for the pause check.
3. **Two new activity actions** — `agent.mode_changed` and `agent.always_on_changed`. Required because mode/alwaysOn changes are meaningful audit events. Added to the shared `ACTIVITY_ACTIONS` const + Zod schemas in main. Per the M7.7 lesson: vocab additions need (a) string in union, (b) zod schema, (c) i18n strings — i18n is PR-B's concern.
4. **`mode` change triggers `restartIfRunning`** (defensive — may affect spawn args/system prompt downstream). **`alwaysOn` does NOT restart** (orchestrator startup-time flag only). **`skills` change DOES restart** (affects `--allowedTools`).
5. **`pause` is reversible, `terminate` is soft-delete.** `paused` keeps the process alive (or null if not running) and parks queue. `terminated` kills the adapter and sets `terminated_at`. The row stays for audit; UI filters it out.
6. **Router pause guard goes in the IPC handler, not in `router.enqueue`.** Reason: the router has no agent reference today (just agentId → state map). Adding the lookup pulls the repo into a place that's currently pure. Cleaner: handler reads agent → if paused, push to a per-handler queue. Actually simpler still: write paused messages to `messages` table normally (so they show in chat history), but **do NOT call `router.enqueue`**. On resume, drain `messages` rows with `delivered_at IS NULL` via a new repo method. Decision: extend `messages` table? No — too invasive. **Final choice:** keep paused messages out of the router state entirely; on resume, the IPC handler re-enqueues anything in a NEW in-memory backlog map keyed by agent. That backlog is process-lifetime only; restart loses it (acceptable for v1 — paused agents are short-lived intent).
7. **`wake-up` is a thin orchestrator helper** — re-enqueues a synthetic `[system] User requested manual run` line. Acts via `router.enqueue` directly; does NOT bypass the pause check (waking a paused agent first requires resume).
8. **`reset-session` is `restartIfRunning` minus the broadcast/status churn.** Actually `restartIfRunning` already does the right thing (`clearSessionId` + status reset + broadcast). The IPC handler just calls it. No new repo method needed.
9. **`hire-from-ui` reuses `agents.create()`.** Same Zod input as the MCP tool's `inputSchema`, with `actor: { kind: 'user' }`. The plan extracts the schema to `packages/shared` so MCP + IPC both reference it.
10. **No emit on `wake-up` to activity stream in PR-A.** Reasoning: the resulting turn-complete + tool calls already produce ample events. Adding `agent.woken_up` would just inflate. Re-evaluate if user finds it useful in smoke.

```ts
import { ipcMain } from "electron";
import {
  IPC,
  HIRE_FROM_UI_INPUT_SCHEMA,
  type Agent,
  type Sender,
} from "@prospero/shared";
import type { AgentsRepository } from "../agents/repository.js";
import type { Router } from "../orchestrator/router.js";
import type { Recorder } from "../activity/recorder.js";

type Broadcast = (event: { kind: string; agentId?: string; companyId?: string }) => void;
type RestartIfRunning = (agentId: string, companyId: string) => void;
type EnsureRunner = (agentId: string) => Promise<void>;
type KillAdapter = (agentId: string) => void;

interface Deps {
  agents: AgentsRepository;
  router: Router;
  recorder: Recorder;
  broadcast: Broadcast;
  restartIfRunning: RestartIfRunning;
  ensureRunner: EnsureRunner;
  killAdapter: KillAdapter;
}

// In-memory backlog for messages received while an agent is paused.
// Wiped on process restart — paused agents are short-lived intent.
const pauseBacklog = new Map<string, Array<{ threadId: string; content: string; sender: Sender }>>();

const enqueueOrPark = (
  agent: Agent,
  router: Router,
  threadId: string,
  content: string,
  sender: Sender,
): void => {
  if (agent.status === "paused" || agent.status === "terminated") {
    const list = pauseBacklog.get(agent.id) ?? [];
    list.push({ threadId, content, sender });
    pauseBacklog.set(agent.id, list);
    return;
  }
  router.enqueue(agent.id, threadId, content, sender);
};

export const registerAgentsLifecycleHandlers = (deps: Deps): void => {
  const { agents, router, broadcast, restartIfRunning, killAdapter } = deps;

  ipcMain.handle(IPC.AGENTS_PAUSE, (_e, payload: { agentId: string; reason?: string }) => {
    const a = agents.getById(payload.agentId);
    if (a === null) throw new Error(`agent not found: ${payload.agentId}`);
    if (a.status === "terminated") throw new Error("cannot pause a terminated agent");
    agents.pause(payload.agentId, payload.reason);
    broadcast({ kind: "status-changed", agentId: payload.agentId, companyId: a.companyId });
    return { ok: true };
  });

  ipcMain.handle(IPC.AGENTS_RESUME, (_e, payload: { agentId: string }) => {
    const a = agents.getById(payload.agentId);
    if (a === null) throw new Error(`agent not found: ${payload.agentId}`);
    if (a.status !== "paused") throw new Error("agent is not paused");
    agents.resume(payload.agentId);
    // Drain backlog accumulated while paused.
    const parked = pauseBacklog.get(payload.agentId) ?? [];
    pauseBacklog.delete(payload.agentId);
    for (const m of parked) router.enqueue(payload.agentId, m.threadId, m.content, m.sender);
    broadcast({ kind: "status-changed", agentId: payload.agentId, companyId: a.companyId });
    return { ok: true, drained: parked.length };
  });

  ipcMain.handle(IPC.AGENTS_TERMINATE, (_e, payload: { agentId: string; reason?: string }) => {
    const a = agents.getById(payload.agentId);
    if (a === null) throw new Error(`agent not found: ${payload.agentId}`);
    killAdapter(payload.agentId);
    agents.terminate(payload.agentId, payload.reason);
    pauseBacklog.delete(payload.agentId);
    broadcast({ kind: "roster-changed", companyId: a.companyId });
    return { ok: true };
  });

  ipcMain.handle(IPC.AGENTS_WAKE_UP, async (_e, payload: { agentId: string }) => {
    const a = agents.getById(payload.agentId);
    if (a === null) throw new Error(`agent not found: ${payload.agentId}`);
    if (a.status === "paused" || a.status === "terminated") {
      throw new Error(`agent is ${a.status}; resume it first`);
    }
    await deps.ensureRunner(payload.agentId);
    const sender: Sender = { kind: "user", id: null, name: "system" };
    router.enqueue(payload.agentId, `wake_${Date.now()}`, "User requested manual run.", sender);
    return { ok: true };
  });

  ipcMain.handle(IPC.AGENTS_RESET_SESSION, (_e, payload: { agentId: string }) => {
    const a = agents.getById(payload.agentId);
    if (a === null) throw new Error(`agent not found: ${payload.agentId}`);
    restartIfRunning(payload.agentId, a.companyId);
    return { ok: true };
  });

  ipcMain.handle(IPC.AGENTS_HIRE_FROM_UI, (_e, payload: unknown) => {
    const parsed = HIRE_FROM_UI_INPUT_SCHEMA.parse(payload);
    const created = agents.create({
      companyId: parsed.company_id,
      name: parsed.name,
      role: parsed.role,
      systemPrompt: parsed.system_prompt,
      mode: parsed.mode ?? "supervised",
      alwaysOn: false,
      templateId: parsed.role_template_id ?? null,
      actor: { kind: "user" },
    });
    broadcast({ kind: "roster-changed", companyId: created.companyId });
    return created;
  });

  return;
};

export { enqueueOrPark, pauseBacklog };
```
